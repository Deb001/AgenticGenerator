# Portfolio Advisory Frontend

## Overview
A modern React single‑page application built with **Vite**, **TypeScript**, **Tailwind CSS**, and **Recharts**. It provides:
- Secure JWT‑based authentication.
- Portfolio list and detailed view with interactive charts.
- Graceful fallback to mock data when the backend is unavailable.

## Prerequisites
- **Node.js** >= 18
- **npm** (comes with Node) or **yarn**
- Backend API running (see the companion backend README) or rely on mock data.

## Setup
```bash
# Clone the repository (if not already)
git clone <repo-url>
cd frontend

# Install dependencies
npm install

# Create an environment file
cp .env.example .env
# Edit .env if your backend runs on a different URL
```

## Development
```bash
npm run dev
```
Open http://localhost:3000 in your browser. The app will automatically reload on code changes.

## Build for Production
```bash
npm run build
# Preview the production build
npm run preview
```
The output is placed in the `dist/` folder and can be served by any static web server.

## Security & Best Practices
- **Content Security Policy** is set in `index.html` to restrict sources.
- All API requests include the JWT token stored in `localStorage`.
- Tailwind CSS is compiled locally; no external CDN is used, eliminating SRI concerns.
- The UI uses semantic HTML elements and ARIA‑friendly components.

## Folder Structure
```
frontend/
├─ src/
│  ├─ components/          # Reusable UI components
│  │  ├─ ui/                # Button, Table, etc.
│  │  ├─ PortfolioList.tsx
│  │  ├─ PortfolioDetail.tsx
│  │  └─ Chart.tsx
│  ├─ context/              # Auth context provider
│  ├─ hooks/                # Custom React hooks
│  ├─ pages/                # Route pages (Login, Portfolio)
│  ├─ services/             # Axios API wrapper
│  ├─ mock/                 # Mock data used when backend is down
│  ├─ App.tsx
│  └─ main.tsx
├─ public/ (generated by Vite)
├─ tailwind.config.js
├─ postcss.config.js
├─ tsconfig.json
└─ vite.config.ts
```
