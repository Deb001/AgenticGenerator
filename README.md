# Simple Calculator App

This is a simple calculator app built with HTML, CSS, and JavaScript. It provides basic arithmetic operations and can be run directly from the browser by opening `index.html`.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division.
- Support for decimal numbers.
- Clear and backspace functionality.
- Responsive design suitable for both desktop and mobile devices.

## Getting Started

### Prerequisites
No special software is required to run this app. Ensure you have a modern web browser installed (like Chrome, Firefox, or Safari).

### Installation
1. Clone the repository:
      git clone https://github.com/your-repo/simple-calculator.git
   cd simple-calculator
   2. Open `index.html` in your preferred browser.

### Running Tests
To run a basic test harness, open `tests/test.html` in your browser. This will call the `evaluate` function with various inputs to ensure it works as expected.

## Usage
- Use the buttons or keyboard to input numbers and operators.
- Press '=' to compute the result.
- Use 'C' to clear the current input.
- Use '⌫' to delete the last character.
