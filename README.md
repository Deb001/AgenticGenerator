# Calculator Project

This project is a simple web-based calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations including addition, subtraction, multiplication, and division. The calculator also includes error handling for invalid inputs and a clear button to reset the display.

## Installation
To install this project, follow these steps:
1. Clone the repository to your local machine using `git clone <repository-url>`.
2. Navigate to the project directory.
3. Open the `index.html` file in a web browser.

## Usage
The calculator can be used by inputting numbers and selecting operations from the buttons provided on the screen or via keyboard inputs. The result of the operation will appear below the input fields. Use the clear button to reset the display at any time.

## Features
- **Basic Arithmetic Operations:** Addition, subtraction, multiplication, division.
- **Error Handling:** Displays an error message for invalid operations or inputs.
- **Keyboard Support:** The calculator supports keyboard inputs corresponding to numbers and basic operations.
- **Clear Button:** Resets the display and allows a new calculation.
