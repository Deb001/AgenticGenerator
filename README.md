# Portfolio Advisory Application\n\n## Overview\nA full‑stack web app for financial advisors to manage Indian equity client portfolios and receive automated Buy/Hold/Sell signals. Backend is built with **FastAPI** and **SQLAlchemy**, frontend with **React**, **TypeScript**, and **Tailwind CSS**.\n\n## Table of Contents\n- [Prerequisites](#prerequisites)\n- [Setup (Development)](#setup-development)\n- [Running the Application](#running-the-application)\n- [Testing](#testing)\n- [Deployment](#deployment)\n\n## Prerequisites\n- Docker & Docker Compose\n- Node.js >= 18\n- Python >= 3.10\n\n## Setup (Development)\n1. **Clone the repository**\n   ```bash\n   git clone <repo-url>\n   cd <repo-folder>\n   ```\n2. **Create a Python virtual environment**\n   ```bash\n   python -m venv venv\n   source venv/bin/activate   # Linux/macOS\n   venv\\Scripts\\activate    # Windows\n   pip install -r backend/requirements.txt\n   ```\n3. **Configure environment variables**\n   ```bash\n   cp .env.example .env\n   # Edit .env with your preferred values\n   ```\n4. **Start PostgreSQL and other services**\n   ```bash\n   docker-compose up -d db\n   ```\n5. **Run database migrations (SQLAlchemy creates tables automatically on first request).**\n6. **Start the FastAPI backend**\n   ```bash\n   uvicorn backend.main:app --reload\n   ```\n7. **Install frontend dependencies**\n   ```bash\n   cd frontend\n   npm install\n   ```\n8. **Start the React development server**\n   ```bash\n   npm run dev\n   ```\n\nThe API docs are available at `http://localhost:8000/docs`.\n\n## Running the Application\n- **Development**: Follow steps 4‑8 above.\n- **Production (Docker)**:\n  ```bash\n  docker-compose -f docker-compose.yml up --build -d\n  ```\n  The backend will be exposed on port 8000 and the frontend on port 5173.\n\n## Testing\n### Backend\n```bash\npytest backend/tests\n```\n### Frontend\n```bash\ncd frontend\nnpm run test\n```\n\n## Deployment\n- Use the provided Dockerfiles (backend/Dockerfile, frontend/Dockerfile) to build images.\n- Deploy to any container orchestration platform (Kubernetes, ECS, etc.).
